# YouTube 双语字幕

在 YouTube 视频上叠加「英文原文 + 中文翻译」双语字幕。翻译免费、无需 API key，支持划词查词、拖动定位、滚轮缩放。

## 功能特性

- **双语字幕**：读取 YouTube 原生字幕，实时叠加英文原文 + 中文翻译两行字幕
- **免费翻译，零配置**：优先使用 Chrome 内置的本地翻译模型（离线、零延迟），不可用时自动回退 Google 翻译免费接口
- **划词查词**：点击英文单词弹出音标释义（有道词典），查词时自动暂停视频、关闭释义自动继续播放
- **自由布局**：中英两行字幕可分别拖动到任意位置（右上角按钮解锁防误拖），一键恢复默认布局
- **滚轮缩放**：Ctrl+滚轮（或 Alt+滚轮）快速调整字号，不会触发浏览器页面缩放
- **独立开关**：英文字幕、中文字幕、划词查词、全屏滚轮屏蔽均可单独开关
- **全屏不打扰**：全屏时屏蔽滚轮手势，不再滑出推荐视频层

## 安装

1. 下载或克隆本仓库
2. 打开 Chrome，访问 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本仓库目录

打开任意 YouTube 视频播放页即可使用。首次进入视频会自动开启原生字幕（CC）；视频没有字幕轨时会提示。

## 使用

### 设置面板（点击工具栏图标）

| 设置项 | 说明 |
| --- | --- |
| 总开关 | 启用/停用双语字幕 |
| 显示英文字幕 | 是否显示英文原文行 |
| 显示中文字幕 | 是否显示中文翻译行 |
| 点击单词查词 | 是否启用划词查词（关闭后单词不再可点） |
| 禁用全屏滚轮 | 全屏时屏蔽滚轮（含 Ctrl+滚轮），避免滑出推荐视频层 |
| 英文字号 / 中文字号 | 两行字号，也可在播放页用滚轮微调 |
| 重置位置 | 把拖乱的字幕恢复默认布局 |

### 播放页交互

| 操作 | 效果 |
| --- | --- |
| Ctrl+滚轮（或 Alt+滚轮）悬停某行字幕 | 只缩放该行字号 |
| Ctrl+滚轮（或 Alt+滚轮）在播放器其他位置 | 两行字号一起缩放 |
| 点击英文单词 | 暂停视频并弹出释义；点别处/ESC 关闭并继续播放 |
| 拖动字幕（需先点右上角按钮解锁） | 分别调整中英字幕位置 |
| 悬停字幕时滚轮缩放 | 不会触发浏览器页面缩放；想缩放页面请把鼠标移出播放器 |

## 常见问题

**需要 Python / PyTorch / 显卡吗？**
不需要。扩展是纯 JavaScript 编写，本地翻译模型由 Chrome 自动下载和管理，用浏览器内置引擎推理，CPU 即可运行。完全不涉及 Python 或深度学习框架的安装。

**字幕不显示 / 只有英文没有中文？**
- 确认视频有字幕轨（自动字幕也可以）；没有字幕的视频无法使用
- 中文翻译：优先走 Chrome 内置本地翻译（较新版 Chrome 才支持，首次需联网下载模型），不支持时走 Google 翻译接口（需联网）；两层都失败时显示原文并提示
- 查词功能需要联网

**修改代码后不生效？**
内容脚本不会热更新：在 `chrome://extensions` 点扩展的「重新加载」，然后刷新 YouTube 标签页。

**只想看中文（或只想看英文）？**
在设置面板里把另一行关掉即可，两行互不影响。

## 技术架构

```
YouTube 原生字幕 DOM ──► native.js（读取/清洗/截句）
                              │
                              ▼
                     translator.js（翻译：Chrome 本地模型 → Google 接口兜底，带缓存限流）
                              │
                              ▼
                     overlay.js（双语覆盖层：渲染/拖动/缩放/查词卡片）
                              ▲
popup.html/js（设置面板）──► main.js（编排：SPA 路由、自动 CC、设置同步）
                              │
                     background.js（查词代理 + 请求头修正）
```

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | MV3 配置 |
| `src/content/native.js` | 读取 YouTube 原生字幕 DOM，输出当前句 |
| `src/content/translator.js` | 翻译引擎：Chrome 内置模型优先，Google 免费接口兜底 |
| `src/content/dictionary.js` | 查词客户端 |
| `src/content/overlay.js` | 字幕覆盖层与全部交互 |
| `src/content/main.js` | 编排与设置同步 |
| `src/popup/*` | 设置面板 |
| `src/background.js` | 查词请求代理、Origin 头修正 |
| `scripts/gen-icons.js` | 图标生成脚本 |

**权限说明**：`storage` 保存设置；`declarativeNetRequestWithHostAccess` 用于查词接口的请求头修正；`host_permissions` 仅包含翻译与词典接口域名。
